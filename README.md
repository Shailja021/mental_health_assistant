# 🧠 AI Mental Health Assistant

An AI-powered Mental Health Assistant that provides supportive conversations and emotional wellness guidance using Natural Language Processing (NLP) and Generative AI. This project is built with Python, Jupyter Notebook for model development, and Streamlit for an interactive web interface.

 **Note:** This project is intended for educational purposes only and is not a replacement for professional mental health care.

---

## 📌 Features

-  AI-powered mental health chatbot
-  Detects user emotions from text
-  Generates supportive and empathetic responses
-  Simple and interactive Streamlit interface
-  Data preprocessing and model development in Jupyter Notebook
-  Fast and user-friendly experience

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/Mental-Health-Assistant.git
```

### 2. Open the Project

```bash
cd Mental-Health-Assistant
```

### 3. Create Virtual Environment (Optional)

```bash
python -m venv venv
```

Activate it

Windows

```bash
venv\Scripts\activate
```

Linux / Mac

```bash
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Project

### Step 1

Open and run the notebook

```
Mental_Health_Assistant.ipynb
```

This notebook performs:

- Data Loading
- Data Cleaning
- Text Preprocessing
- Model Training
- Model Evaluation
- Saving the trained model

### Step 2

Run the Streamlit application

```bash
streamlit run app.py
```

The application will open automatically in your browser.
